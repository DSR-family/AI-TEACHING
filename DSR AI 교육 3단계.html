시작하기 전

3단계 실습 교육은 전산팀에서 제작한 교육 영상을 통해 진행됩니다.
본 페이지는 개발 과정을 처음부터 끝까지 따라가 보는 실습형 퀴즈입니다.
저장소 생성부터 결과물 업로드까지, 실제와 동일하게 구성된 연습 화면에서 순서대로 진행합니다.

세 가지 과정을 모두 완료한 뒤 교육 완료 버튼을 눌러야 3단계 교육 이수가 인정됩니다.

승인 요청 판단하기

저장소를 생성한 뒤에는 Claude를 활용하여 개발을 진행합니다. 개발 과정에서 Claude는 작업을 수행하기 전에 사용자에게 승인을 요청합니다. 요청 내용을 확인하고 적절한 응답을 선택하시기 바랍니다.

문항 1

실습 중 다음과 같은 승인 요청이 표시되었습니다
Claude Code
Claude가 새 가상환경을 생성하고 pip를 준비하도록 허용하시겠습니까?

문항 2

실습 중 다음과 같은 승인 요청이 표시되었습니다
Claude Code
Claude가 run Check git remote, hooks path, and user config하도록 허용하시겠습니까?

문항 3

실습 중 다음과 같은 승인 요청이 표시되었습니다
Claude Code
Claude가 Python 파일의 문법을 검사하도록 허용하시겠습니까?
세 문항 모두 정답을 선택하면 다음 단계로 진행할 수 있습니다. 오답 시 다시 선택할 수 있습니다.
